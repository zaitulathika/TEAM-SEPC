TEAM SEPC – Leadership Website
==============================
Open index.html to start.

PAGES
index.html        = short leadership-focused homepage
leadership.html = leadership philosophy & development journey
team.html         = all team members
projects.html     = project, improvement & impact stories
gallery.html      = activity photos

PHOTOS
Put real photos in images/team/ or images/gallery/.
Then edit the relevant HTML page and change the .svg filename to your .jpg/.png filename.

TEXT
Open HTML files in VS Code / Notepad++ and replace placeholder names, roles, figures and descriptions.

STYLE / MOBILE
css/style.css controls the design and responsive phone/tablet/desktop layout.
js/script.js controls mobile navigation and scroll reveal animation.

Recommendation: keep index.html short. Put detailed information on the other pages.
